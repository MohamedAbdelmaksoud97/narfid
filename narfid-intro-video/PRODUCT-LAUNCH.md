## Edit and render

Select `NarfidProductLaunch` in Remotion Studio. Each substantial scene is separately registered in `Product-Launch-Scenes`, with independently authored timeline nodes. Source: `src/product-launch/`.

```powershell
node scripts/make-product-launch-score.mjs
npm run lint
npm run build
npx remotion render NarfidProductLaunch out/narfid-product-launch.mp4 --codec=h264 --crf=18 --concurrency=2
& node_modules/@remotion/compositor-win32-x64-msvc/ffmpeg.exe -i out/narfid-product-launch.mp4 -map 0:v:0 -map 0:a:0 -c:v copy -af 'loudnorm=I=-22:TP=-2:LRA=11' -c:a aac -b:a 192k -ar 48000 -movflags +faststart out/narfid-product-launch-master.mp4
```

The delivered file is `out/narfid-product-launch-master.mp4`. Mastering raises the quiet instrumental mix to approximately −22 LUFS, with a −2 dBTP limiter, while copying the encoded video. The unmastered export is retained separately.
