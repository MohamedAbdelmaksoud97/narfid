# إدارة علاقات العملاء في نرفد

هذا دليل داخلي للقسمين المحميين بصلاحيات مجلس الإدارة. البيانات محفوظة في Supabase، وليست في تخزين المتصفح.

## العملاء المحتملون — `/board/leads`

- أضف المؤسسة وفروعها وبيانات التواصل والمدينة والاحتياج ومصدر التعارف.
- عيّن مسؤولًا من أعضاء المجلس، وأولوية، وميزانية تقديرية، وموعدًا للتواصل والتعاقد المتوقع.
- حدّث المرحلة: جديد، تم التواصل، مؤهل، عرض توضيحي، عرض سعر، تفاوض، أو لم يتم الاتفاق مع توثيق السبب.
- أضف جهات اتصال إضافية، وسجل المكالمات والاجتماعات والملاحظات، ومهام المتابعة ومسؤوليها ومواعيدها.
- استخدم البحث وفلاتر المرحلة والمسؤول والأولوية والمتابعة المتأخرة والأرشيف، أو تصدير الملفات الحالية بصيغة CSV.

## التعاقد والتحويل

من الملف اختر «تحويل إلى عميل»، ثم أدخل تفاصيل الاتفاق الفعلي: اسم العقد ومرجعه ومدته وقيمة الاشتراك السنوي ورسوم التجهيز ونطاق الخدمة ورابط مستند العقد عند توفره.

ينتقل الملف نفسه إلى قسم العملاء مع الاحتفاظ بجهات الاتصال والتواصل والمهام والتاريخ. تُنشأ قائمة تجهيز من سبع مهام وسجل أولي لبيئة الإنتاج. تتم العملية كوحدة واحدة؛ فشل إنشاء العقد لا يترك تحويلًا جزئيًا، وإعادة الطلب لا تنشئ عقدًا أو ملفًا مكررًا.

يمكن إضافة عميل متعاقد مباشرة من قسم العملاء ثم تسجيل عقده؛ هذا مناسب لإدخال العملاء الحاليين.

## العملاء — `/board/clients`

- **الملف:** بيانات المؤسسة ونطاق الخدمة ومسؤول العلاقة وحالة العميل: قيد التجهيز، نشط، متوقف مؤقتًا، أو انتهت العلاقة.
- **المتابعات والتجهيز:** مهام قابلة للإضافة والتعديل والحذف وتحديد المسؤول والموعد، مع إكمالها بمربع الاختيار ومؤشر لتقدم التجهيز.
- **العقود والدفعات:** عقود متعددة عبر السنوات، ورسوم سنوية وتجهيز منفصلة، وتسجيل دفعات جزئية مقابل عقد موقّع، وحساب المحصّل والمتبقي.
- **التشغيل والتحديثات:** بيئتا الإنتاج والاختبار، ورابط النظام ومرجع قاعدة البيانات والمستودع والإصدار والاستضافة وحالة النسخ الاحتياطي وتاريخ اختبار الاستعادة.
- **الدعم والتطوير:** طلبات دعم ومشكلات تقنية وتطوير وتكامل، مع المسؤول والأولوية والحالة والموعد والتفاصيل وملخص الحل.
- **سجل النشاط:** إجراءات إنشاء السجلات وتعديلها وحذفها والتحويل والأرشفة، مع العضو المنفذ وتاريخ الإجراء.

تُظهر قائمة العملاء مؤشرات العملاء النشطين والتجهيز والتجديدات القريبة خلال ٣٠ يومًا أو المنتهية والمتبقي من العقود الموقّعة. فلاتر المتابعات والتجديدات تنبّه داخل القسم؛ لا تُرسل رسائل أو إشعارات خارجية تلقائيًا.

## ضوابط التشغيل

- «تجهيز تجديد» ينشئ مسودة لسنة جديدة دون استبدال العقد السابق؛ راجع الاتفاق ثم غيّر حالتها إلى موقّع.
- لا يُقبل تداخل فترات عقدين موقّعين لنفس العميل. يمكن حفظ عرض التجديد كمسودة قبل توقيعه.
- المبالغ بالريال السعودي، وتُحفظ كهللات صحيحة لتجنب أخطاء الكسور. هذه سجلات تحصيل إدارية؛ لا تُنفّذ خصمًا مصرفيًا أو استردادًا أو إصدار فاتورة ضريبية.
- لا تُعدّل الدفعة بعد تسجيلها؛ ألغِ تسجيلها بسبب واضح ثم أضف السجل الصحيح. يبقى تاريخ الدفعة محفوظًا، وتُرفض الدفعات التي تتجاوز المتبقي.
- تُحذف العقود المسودة فقط. يتطلب إلغاء عقد ذي دفعات مراجعة سجلات التحصيل أولًا.
- أرشف الملف للاحتفاظ بتاريخه؛ يصبح للقراءة حتى استعادته. أرشفة الملف لا توقف نظام العميل أو اشتراكه فعليًا.
- بيانات بيئة التشغيل توثيق ومتابعة؛ إضافة السجل أو تغيير حالته لا ينشر تطبيقًا ولا ينشئ قاعدة بيانات ولا يشغّل نسخًا احتياطيًا تلقائيًا.
- تُحفظ كلمات المرور ومفاتيح الوصول في مدير أسرار، ويُسجل داخل القسم مرجع المشروع فقط. اعتماد حالة «يعمل» يحتاج رابط النظام ومرجع قاعدة البيانات، واعتماد اختبار الاستعادة يحتاج تاريخًا.
- عند تعديل عضو آخر للسجل أثناء فتحه، يُرفض الحفظ القديم مع طلب تحديث البيانات بدل استبدال التعديل الأحدث.

## الصلاحيات والتحقق

كل الصفحات وواجهات API محمية بجلسة فعالة وعضوية مجلس نشطة، والجداول مقيّدة بسياسات RLS. لا تُتاح بيانات CRM للزوار أو للحسابات خارج المجلس. طلبات التعديل تتحقق من المصدر وحجم المدخلات، وتُصدّر CSV مع حماية خلايا الصيغ.

التحقق:

- `npm run test:crm` لاختبارات القيم والتواريخ والأموال والروابط والتصدير.
- `npm run test:crm:browser` مع `AUTH_TEST_BASE_URL` لخادم الاختبار: تجربة Chromium كاملة ببيانات مؤقتة تُحذف في النهاية، دون طباعة حسابات الدخول. يحتاج ملفات الإدارة المحلية الخاصة واتصال مشروع الاختبار.
- `node --env-file=.env.local scripts/article-db.mjs supabase/tests/crm.sql` لاختبارات قواعد البيانات والصلاحيات والتحويل والتحصيل داخل معاملة تُلغى في النهاية.
- `npm run lint` و`npx tsc --noEmit` و`npm run build` للتحقق من التطبيق.

Migration: `supabase/migrations/20261018173942_narfid_crm.sql`. لا تُعد تشغيلها يدويًا على قاعدة طُبّقت فيها بالفعل؛ استخدم migration جديدة لأي تغيير لاحق.
