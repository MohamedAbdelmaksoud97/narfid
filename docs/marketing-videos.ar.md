# إنتاج فيديوهات نرفد محليًا

**قرار المالك — ١٣ نوفمبر ٢٠٢٦:** إنتاج الفيديوهات ومونتاجها وحفظ ملفات MP4 يكون على الكمبيوتر المحلي، والنشر مباشرة على المنصة المطلوبة. أُزيل قسم الفيديوهات من لوحة إدارة موقع نرفد وروابطه وصفحته ومسارات API الخاصة به.

تبقى الأفكار الخمسون `NV-001`–`NV-050` في `lib/marketing/video-briefs.ts` مرجعًا محليًا للإنتاج؛ الأفلام التجريبية السابقة مستقلة عنها. لم تُحذف ملفات Remotion أو مخرجات الفيديو المحلية.

## الأوامر المحلية

```powershell
npm run marketing:video -- brief NV-001
npm run marketing:video -- verify NV-001 --file "absolute/video.mp4" --qa ".private/video-runs/NV-001-qa.json"
```

لا تقرأ هذه الأوامر بيانات دخول اللوحة أو `.env.local` ولا تتصل بخدمات بعيدة. أُلغي تسجيل الحالة والرفع للوحة عبر `status` و`start` و`revise` و`finish`، وأُلغي حد التخزين السابق البالغ ٥٠ MiB من الفحص المحلي. يفحص `verify` مقاس ومدة فكرة الحملة والترميز والصوت وفك الملف وتقرير المراجعة المطابق لبصمته. راجع [إجراء الإنتاج المحلي](../.agents/skills/narfid-video/references/local-production.md) و[مهارة الفيديو](../.agents/skills/narfid-video/SKILL.md).

يُسلّم الفيديو كرابط محلي مع المصدر القابل للتعديل. يُنشر على المنصة الخارجية فقط بطلب المالك، ثم يُتحقق من المنشور هناك. حفظ الملف أو تصديره لا يعني نشره.

الترحيلات التاريخية والجداول وملفات التخزين السابقة بقيت دون حذف بيانات في هذا التعديل. لم تعد لها صفحة أو API للفيديوهات في تطبيق الموقع، ولا يستخدمها أمر الإنتاج المحلي.
