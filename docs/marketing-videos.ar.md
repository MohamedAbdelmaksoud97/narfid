# خطة فيديو نرفد

اعتمد المالك الاتجاه والتوزيع في ١١ نوفمبر ٢٠٢٦. الهدف جذب أصحاب ومديري المؤسسات الرياضية لطلب عرض توضيحي مع محتوى عملي يفيد التشغيل والموظفين، ودعوات بيع انتقائية. هذه خطة نصوص وإدارة إنتاج؛ لا تتضمن إنتاج الفيديوهات الخمسين أو نشرها الآن.

## المحتوى

المكتبة: `/board/marketing/videos`، وتظهر من صفحة التسويق وتنقلها. مصدر النصوص الوحيد `lib/marketing/video-briefs.ts`، والعقد والتوقيع والمقاس في `video-plan.ts`. المعرّفات الدائمة `NV-001`–`NV-050` لا تتغير بتغيير النص أو التصنيف. الأفلام السابقة كلها تجريبية وخارج الخطة والسجل.

| النوع | العدد | أمثلة |
| --- | ---: | --- |
| مواقف ونصائح تشغيل | ٢٠ | تسليم الوردية، متابعة التجديد، الحجوزات، الأكاديميات، الوجبات والفروع |
| دورات عمل المنصة | ١٥ | العضوية، الحضور، التحصيل المجزأ، البيع والمرتجعات، المطبخ والصلاحيات |
| قرارات تقنية واعتراضات | ١٠ | اختيار النظام، التطبيق، البوابات، النقل والتكاملات وحدود المالية والمكونات |
| نرفد وخدماتها | ٥ | التعريف، ترابط الأقسام، الشراكة التقنية، الهوية البصرية والعرض |

لكل فيديو جمهور وهدف ومعالجة بصرية ومشاهد محددة المدة، ونص شاشة وتعليق وتوجيه حركة وصوت ووصف منشور ودعوة مناسبة. مدد النصوص الحالية ٣٧–٣٨ ثانية تقريبًا، داخل المدى المعتمد ٢٥–٤٥ ثانية. يضيف مصدر العقد مشهد الخاتمة الثابت مرة واحدة. الترتيب المقترح يتناوب بين الأنواع، بلا مواعيد نشر أو وعود بإيقاع ملزم.

الفيديو الأساسي مشترك لإنستجرام وإكس ولينكدإن وفيسبوك وسنابشات، بمقاس 1080×1920 و30fps. ليست هناك ٢٥٠ فكرة مستقلة. توائم صياغة الوصف ومتطلبات الرفع مع المنصة عند النشر. الفلاتر تشمل البحث ونوع المحتوى وحالة الإنتاج والمنصة وحالة النشر، وتفتح البطاقة السيناريو الكامل ونسخ الوصف أو التعليق أو جميع التفاصيل.

المحتوى مستند إلى مهارة NARFID و`lib/brand.ts` وتدقيقي المنصة `platform-backend-audit.md` و`platform-frontend-audit.md`. لقطات المنتج المستقبلية تُصوّر محليًا ببيانات خيالية وفق مهارة الفيديو، وليست شهادات عملاء. لا تفترض النصوص ربطًا حكوميًا أو دعم كل البوابات أو تطبيقًا مشمولًا أو ERP مكونات. مصدر UI-system الكامل غير موجود؛ استُخدم المرجع المتاح `supabase.DESIGN.md` مع Tajawal وRTL ومكوّنات shadcn/Base UI الحالية، وفق السابقة الموثقة في `landing-page.md`.

## الصوت

الخاتمة المعتمدة اتجاهًا: نغمة أصلية قصيرة وعبارة **«نرفد… سندك التقني»** بصوت رجالي هادئ بلكنة سعودية خفيفة، ثلاث ثوانٍ. تُراجع عينة أولى ويعتمدها المالك ثم تُحفظ مع مصدر الصوت وإعداداته وحقوق الاستخدام وبصمة الملف. تُستخدم العينة نفسها في كل فيديو دون تغيير السرعة أو إعادة توليدها. لا توجد عينة مُنتجة أو ترخيص صوت جديد في هذا التسليم.

المصدر المقترح للتعليق الصوتي ElevenLabs عبر أداة Higgsfield المتصلة؛ جرى التحقق من توفر المحرك في كتالوج الإضافة ومن [دعم العربية في المرجع الرسمي](https://elevenlabs.io/docs/overview/capabilities/voices). اعتماد نبرة سعودية يحتاج الاستماع للعينة الفعلية، ولا يُستنتج من دعم العربية وحده. اختيار الصوت وتكلفة التوليد عند بدء الإنتاج؛ لا تُشترى اشتراكات ضمن مهمة التخطيط. Remotion يزامن الملفات المحلية مع الحركة بعد إنتاج الصوت.

## السجل والملفات

`marketing_video_productions` يحوي ٥٠ سجلًا مشتركًا للحالة والمحاولة والمراجعة وبيانات آخر ملف. `marketing_video_publications` يحوي ٢٥٠ سجلًا مستقلًا بمفتاح الفيديو والمنصة. RLS تسمح لأعضاء الإدارة النشطين فقط؛ التعديل يتطلب النسخة الحالية، والأزمنة وهوية المعدّل تُضبط في قاعدة البيانات. الـAPI لا يعرض هوية المعدّل. السجل يُحدّث كل ٣٠ ثانية أثناء ظهور الصفحة وعند العودة أو الضغط على التحديث، وتتعطل الكتابة عند تعذر التحقق من الحالة.

تبدأ الحالات بـ«مخطط»، ثم «قيد الإنتاج»، مع «يحتاج تعديل» عند الحاجة، و«جاهز» بعد التحقق والرفع. يمكن للواجهة تسجيل الحالات غير المكتملة؛ «جاهز» يُضبط عبر أمر الإنتاج بعد التحقق. النشر مفتاح مستقل لكل منصة مع وقت تسجيل يمكن إلغاؤه. هذا السجل لا ينشر محتوى خارجيًا، ووقت التسجيل ليس تاريخ نشر مستوردًا.

الأمر `npm run marketing:video -- brief|status|start|revise|verify|finish NV-001` يستخدم حساب الرئيس العادي، ويحفظ حالة المحاولة محليًا في `.private/video-runs`. فحص `verify` محلي بلا تسجيل دخول، ويفحص الأبعاد والمدة وH.264/AAC و30fps وفك الترميز الكامل وبصمة التوقيع وارتباط صوته بالخاتمة وتقرير المراجعة المطابق لبصمة الفيديو. `finish` يرفع ملفًا ثابتًا إلى bucket خاص `marketing-videos`، يعيد تنزيله للتحقق من بصمته، ثم يربط الملف بالحالة ويقرأ النتيجة. [الإجراء والحقول والأوامر](../.agents/skills/narfid-video/references/board-production.md).

المسار داخل التخزين: معرّف الفيديو / معرّف المحاولة / بصمة MP4. لا استبدال للملف؛ كل مراجعة لها محاولة جديدة. لا توجد سياسات تعديل/حذف ملفات لأعضاء اللوحة. حد الملف ٥٠ MiB؛ تُضبط جودة التصدير داخل الحد بدل تضمين MP4 في Git أو حزمة Next. التنزيل والمعاينة يمران بتحقق العضوية ثم رابط تخزين موقّع قصير العمر؛ المخرجات السابقة تبقى متاحة إذا تغيرت حالة العمل.

الترحيل: `20261111123654_narfid_marketing_video_plan.sql`. طُبق على قاعدة لوحة نرفد وسُجل في تاريخ الترحيلات. لا يصل هذا المسار إلى Supabase الإنتاجي للنظام المرجعي.

## التحقق

اختبارات `test:marketing:videos` تتحقق من استقلال الأفكار وتوزيعها وتوقيتها ومساحة قراءة التعليق، ورفض هويات ومدخلات غير صالحة والتسجيل غير المتحقق لحالة جاهز، وتمييز عينة الصوت عن الصمت أو نغمة أخرى. اختبارات SQL في `supabase/tests/marketing-videos.sql` تعمل داخل transaction ملغاة وتفحص عزل الصلاحيات والمراجعات والمحاولة والملف وسياسات التخزين واستقلال المنصات. اختبار Chromium `tests/browser/marketing-videos.spec.ts` يفحص الدخول والفلاتر والنصوص والنسخ والحالات والحفظ بعد إعادة التحميل، وفشل السجل والتعافي والهاتف، مع استعادة الحالات الأصلية.
