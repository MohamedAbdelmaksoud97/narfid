# محرر مقالات نرفد

نتائج التشغيل على Chromium ونسخة الإنتاج، وفحص الصلاحيات وتنظيف بيانات التجربة، موثقة في [تقرير التحقق](./article-editor-verification.md).

## الاستخدام

سجّل الدخول بحساب مجلس الإدارة، ثم افتح **إدارة المقالات** من `/board` أو `/board/articles`. زر **مقال جديد** ينشئ مسودة حقيقية في Supabase ويُفتح المحرر على `/board/articles/[id]/edit`.

- عنوان وملخص، غلاف مع وصف بديل، تصنيف، وسوم، رابط قابل للتعديل، وعنوان ووصف لمحركات البحث.
- Tiptap Simple Editor الرسمي المجاني، مُكيّف مع ألوان نرفد وخط Tajawal. تنسيق النص والعناوين H1–H6 والقوائم والمهام والاقتباس والكود والجداول، الألوان والتمييز والمحاذاة واتجاه الفقرة، الروابط، الصور مع الوصف والتعليق وتغيير الحجم، وفيديو YouTube.
- البحث والاستبدال والقائمة السياقية وعدّ الكلمات والحروف. الحفظ التلقائي بعد 1.8 ثانية، والحفظ اليدوي عبر الزر أو Ctrl/⌘+S.
- معاينة التعديلات داخل الصفحة. النشر أو إلغاء النشر، مع الاحتفاظ بالمسودة.
- تحذير عند مغادرة المحرر برابط أو أزرار الرجوع/التقدم أو إعادة تحميل الصفحة إذا توجد تعديلات غير محفوظة. رسائل أخطاء واضحة، إعادة محاولة، وتنزيل نسخة JSON لحماية العمل عند تعارض التعديلات.
- قائمة الإدارة تعرض 20 مقالًا في الصفحة، والمكتبة العامة 12 مقالًا، مع صفحات تالية وسابقة.

## البيانات والصلاحيات

تم تطبيق وتسجيل `supabase/migrations/20261013193254_nerved_articles.sql` في مشروع Supabase الحالي. استُخدمت Management API لإنشاء المخطط ثم تسجيله دون إعادة تنفيذه؛ طابقنا اسم الملف المحلي مع الإصدار الذي أنشأه سجل migrations الفعلي.

| المصدر | الاستخدام | الوصول |
| --- | --- | --- |
| `board_members` | عضوية تحرير حية للحسابات الخمسة الموجودة | العضو يقرأ صفه فقط؛ التعديل إداري |
| `article_categories` | تصنيفات حقيقية لإدارة المحتوى | قراءة عامة؛ إدارة من Supabase |
| `articles` | النسخة العاملة وTiptap JSONB والبيانات الوصفية | مجلس الإدارة النشط فقط، مع RLS |
| `article_publications` | نسخة مستقلة من آخر نشر صريح | قراءة عامة؛ تعديل بواسطة مجلس الإدارة |
| `article-media` | صور المقالات | bucket خاص؛ RLS للرفع والقراءة |

الحفظ التلقائي لمقال منشور يحدّث المسودة فقط. **نشر التحديث** ينقل نسخة جديدة للعرض العام داخل معاملة واحدة. **إلغاء النشر** يحذف النسخة العامة ويمنع قراءة الصور العامة، ويحتفظ بالمسودة والصور في المساحة الخاصة.

دوال النشر `security invoker` ذات `search_path` ثابت، ولا تتجاوز RLS. رقم `revision` يُحدّث بقاعدة البيانات، ويمنع أن يكتب تبويب أو عضو فوق تعديل أحدث. لا تستخدم طلبات التطبيق Secret Key أو Access Token: تستخدم جلسة المستخدم والمفتاح العام. مفتاح الإدارة يستخدم في أدوات التشغيل والاختبارات فقط.

السماح بالتحرير يحتاج فحص Auth حيًا باستخدام حماية مجلس الإدارة الموجودة **وعضوية `board_members.active`**. لإلغاء الوصول، عطّل العضوية في الجدول، وألغِ `narfid_board_member` من app_metadata إذا كان المقصود منع دخول مجلس الإدارة كله. لا تعتمد الصلاحيات على user_metadata أو إخفاء الأزرار.

رفع الصور يمر من API محميًا بنفس المصدر، يتحقق من الحجم (5 MiB) وMIME والتوقيع وفك تشفير الصورة فعليًا باستخدام Sharp، بحد أقصى 40 مليون بكسل و10 آلاف بكسل لكل بُعد. يقبل PNG/JPG/WebP/GIF فقط؛ لا يقبل SVG أو Base64. أسماء الملفات UUID مستقلة لكل رفع؛ لا يوجد overwrite. لا تُتاح للزوار إلا الملفات المشار إليها بالنسخة المنشورة، وليس كل ملفات مجلد المقال.

## العرض العام وSEO

`/articles` مكتبة المقالات، و`/articles/[slug]` عرض الخادم للنسخة المنشورة. Tiptap Static Renderer منفصل عن المحرر، يعيد التحقق من JSON، ويستخدم React دون حقن HTML من المحتوى. تُعرض الصور بتعليقاتها والجداول بعروض الأعمدة، والفيديو عبر YouTube nocookie. الروابط آمنة، وعنوان المقال هو H1، وعناوين المحتوى تُعرض H2–H6.

Metadata تشمل title/description/canonical وOpen Graph وTwitter وArticle JSON-LD، مع escaping للبيانات المنظمة. تحت Cache Components/PPR في Next.js، المقال غير المتاح قد يُرجع HTTP 200 إذا بدأ البث بالفعل، لكن يعرض not-found ويضيف `robots=noindex` دون أي محتوى خاص. هذه دلالة Next.js الموثقة؛ اختباراتنا تتحقق من عدم تسريب المحتوى ووجود noindex، ولا تفترض 404 بعد بدء البث.

## المهارات والحزم

تم تنفيذ `npx skills add ueberdosis/tiptap --skill tiptap` وقراءة `.agents/skills/tiptap/SKILL.md`، ثم تثبيت القالب بواسطة `npx @tiptap/cli@latest add simple-editor`. أُزيلت صفحة `/simple` ومحتوى العرض التجريبي، واستُبدل مسار رفع الصور التجريبي بالتكامل الفعلي.

كل حزم `@tiptap/*` مثبتة على **3.32.0**، وتشمل React/PM/StarterKit، الإضافات المجانية المطلوبة، وStatic Renderer. القالب وTiptap تحت MIT؛ لا توجد حزم `@tiptap-pro` أو خدمة Tiptap Cloud. مكونات القالب تستخدم Floating UI/Radix، بينما نماذج الموقع تستمر على shadcn Base UI الموجود. أضيفت Sass، وSharp 0.35.5 للتحقق من الصور، وPlaywright 1.64.0 وtsx للاختبارات. التراخيص التجارية لهذه الإضافات مفتوحة (MIT/Apache-2.0).

استخدمنا `useEditor` مع `immediatelyRender:false` و`shouldRerenderOnTransaction:false` للتوافق مع القالب الرسمي. المحرر memoized، والقوائم/العدادات تشترك في حالة المحرر، ولا تعيد استبدال محتواه عند الحفظ. عُدّلت hooks من القالب لتوافق React الحالي؛ توجد استثناءات ESLint موضعية موثقة لتمرير callback refs إلى cloneElement وlodash، دون تعطيل قواعد المشروع عمومًا.

اتبعت مهارات shadcn وSupabase وPostgres أيضًا. مسار UI-system/SKILL.md المذكور في AGENTS غير موجود؛ مواصفة الألوان الموجودة هي `.agents/skills/UI-system/supabase.DESIGN.md`، واستُخدمت مع Tajawal المطلوب.

## البيئة والتشغيل

استمرار استخدام `NEXT_PUBLIC_SUPABASE_URL` و`NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` الموجودين. أُضيف `SUPABASE_ACCESS_TOKEN` محليًا في `.env.local` لتنفيذ المخطط؛ لا يلزم وضعه في بيئة تطبيق الإنتاج. `SUPABASE_SECRET_KEY` الموجود مطلوب لأدوات تجهيز الحسابات والاختبارات التي تنظّف بياناتها، ولا يُرسل للمتصفح. `.env.local` و`.private` ونتائج الاختبارات مستثناة من Git.

اضبط `NEXT_PUBLIC_SITE_URL` على عنوان الموقع النهائي في الإنتاج حتى تكون canonical وصور Open Graph وJSON-LD بالدومين الصحيح.

```powershell
npm run dev
npm run test:articles
npm run test:auth
npx tsc --noEmit
npm run lint
npm run build
npm run start -- -p 3015
$env:AUTH_TEST_BASE_URL='http://127.0.0.1:3015'
npm run test:articles:http
npm run test:articles:browser
node --env-file=.env.local scripts/verify-article-build.mjs
```

قبل أول اختبار متصفح على جهاز جديد: `npx playwright install chromium`. الاختبارات تقرأ حسابًا مجهّزًا من `.private/board-accounts.json` دون كتابة كلمات المرور في الكود أو حفظ جلسات المتصفح في الملفات. تنشئ مقالات/صورًا ومستخدم اختبار منعزلًا، ثم تحذف هذه البيانات في finally. لقطات فحص المحرر في `.private/article-qa`، ولا تُنشر.

## النطاق الحالي

لا توجد إضافات مدفوعة أو اشتراك Tiptap مطلوب. لم نضف slash commands أو سحب وترتيب جميع البلوكات؛ هذه كانت اختيارية. تغيّر أحجام الصور وسحب الصورة نفسها مدعومان بالإضافة المجانية. هوية الموقع الحالية داكنة فقط، فالمحرر يتبعها. إدارة التصنيفات تتم حاليًا من Supabase؛ واجهتها الإدارية ليست ضمن طلب إنشاء المقالات.

المحتوى غير المحفوظ يبقى في الذاكرة مع تحذيرات المغادرة والنسخ الاحتياطي عند الأخطاء؛ لم تُضف قاعدة offline أو تعاونية حية أو سجل نسخ تاريخي. البيانات المرجعية عبارة عن تصنيفات، ولا توجد مقالات إنتاج تجريبية.
