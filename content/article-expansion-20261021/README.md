## المصادر والتنفيذ

- ملفات `articles-01.json` إلى `articles-06.json` تحتوي النصوص وموجز السؤال والجمهور والزاوية المختلفة والغلاف والروابط السياقية؛ خمس مقالات في كل ملف للتنظيم فقط.
- [بناء المحتوى](../../lib/articles/article-expansion-content.ts) يحول المصادر إلى Tiptap JSON بعناوين H2 وروابط داخل الفقرات، ويمرر الحقول إلى المدققات الحالية. الهوية العامة `nerved-team`، والمراجعة التحريرية التالية 2027-01-21 أو عند تغير مؤثر في المصدر أو المنتج.
- الأغلفة تعيد استخدام خمس صور مناسبة من `content/article-covers` و`content/seo-campaign/covers`، بعد فحصها بصريًا. المصدر والمصور والترخيص والوصف البديل محفوظة مع بيانات كل مقال. ليست الصور عملاء نرفد، ولا يُستدل منها على جنسية حقيقية.
- أمثلة المبالغ والنسب افتراضية موسومة داخل النصوص؛ لا نتائج عملاء مختلقة أو أسعار بيع للمنصة أو سياسات قانونية أو نصائح علاجية. لا تُنسب أدوات المنافسين أو وظائفهم إلى نرفد.
- المحتوى مفيد دون شراء منتج؛ بعض الفقرات تربط بحل مناسب عند الحاجة، وأكثر المقالات تربط بإجراءات تعليمية ذات صلة. لا يضيف المساعد خاتمة بيع موحدة أو بطاقة حل إلزامية.
- `manifest.json` يثبت المعرّفات والروابط وبصمات المصادر والصور؛ ليس سجلًا لحالة النشر.

## الاستيراد القابل للاستكمال

من جذر المشروع:

```powershell
# تحقق محلي دون قاعدة بيانات
node --import=tsx scripts/import-article-expansion.ts

# بعد مراجعة تغيير المصادر فقط؛ تحديث manifest دون نشر
node --import=tsx scripts/import-article-expansion.ts --prepare

# عند تفويض استكمال النشر فقط
node --env-file=.env.local --import=tsx scripts/import-article-expansion.ts --apply
```

الأداة مستقلة عن دفعة الثمانية وحملة العشرين؛ تعيد استخدام مدققات المقالات وStorage الخاص وRPC النشر الحالي وجلسة مجلس إدارة فعلية. تتحقق من التصنيفات الحالية واصطدام المعرّفات والروابط والمراجعات وبصمات الصور، وتتعافى من رد حفظ أو نشر ضائع فقط عند تطابق السجل المتوقع. تُنشر المقالات بالتتابع بعد التحقق.

القفل والتقدم وجرد ما قبل التنفيذ وتقارير التحقق في `.private/article-expansion-20261021` خارج Git. لا تحذف سجل الاستكمال لإجبار تحديث منشور. المقال المكتمل يُتخطى عند إعادة التشغيل مع الحفاظ على تحريره أو إلغاء نشره لاحقًا؛ استخدم المحرر مع أحدث مراجعة للتعديل. إذا توقف الاستيراد راجع الخطأ قبل المتابعة، وأزل قفلًا متروكًا فقط بعد التأكد من انتهاء العملية.
