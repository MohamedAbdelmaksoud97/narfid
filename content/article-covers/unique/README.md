المصدر المعتمد للغلاف الحالي هو المقال الحي مع هذا الكتالوج، وليس دالة بناء حملة تاريخية. أبقينا مصادر دفعات الثمانية والعشرين والثلاثين وبصماتها وسجلات استكمالها دون تغيير، حتى لا تُكتب فوق تعديلات المحرر اللاحقة.

# تحقق محلي من الملفات والأبعاد والحقوق وعدم تكرار الصورة الأصلية أو محتواها
node --import=tsx scripts/refresh-unique-article-covers.ts

# جرد ومراجعة السجلات الحية دون تعديل

# تنفيذ التغييرات المعتمدة عبر التخزين الخاص ومدققات المقالات وRPC النشر المعتاد

# تحقق من الأغلفة المنشورة وبصماتها وحفظ بقية المحتوى والمسودات
